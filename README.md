# Kelompok 1: Kode 01 Pengumpulan & Kurasi Video Kabut Asap

## 1.Deskripsi Dataset
Berisi dokumentasi berupa Video, Link URL, dan Deskripsi
Setiap anggota kelompok wajib mengumpulkan minimal 10 video dan membuat folder berisi Link URL dan Deskripsi untuk setiap video untuk mereka commit masing-masing.

## 2.Cara Mengunduh
Untuk mengunduh tekan tombol <>code disebelah kiri berwarna hijau lalu tekan Download ZIP yang ada di paling bawah opsi. Setelah selesai mengunduhnya klik kanan file zip tersebut lalu extract file zip tersebut.
